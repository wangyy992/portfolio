游戏拆解 / 03

Royal Match

红海品类里，后来者靠什么后来居上

核心论点 Royal Match 几乎没有玩法创新——三消的核心规则是行业公共资产。 它的胜负手在两个地方：一是把「失败」而不是「通关」当成主战场来设计， 因为失败才是玩家在这个游戏里最高频经历的事件； 二是把 meta 层严格限制为纯正反馈，不引入第二个失败点，让情绪曲线单向可控。 在一个成熟到没有玩法红利的品类里，竞争维度已经从「玩法创新」转移到「体验打磨 + 买量效率」。

01问题定义

三消是移动游戏里最红海的品类。《Candy Crush Saga》从 2012 年起长期占据畅销榜前列， 规则已经被完全公开、被无数产品复刻，玩法层面没有任何秘密可言。

Dream Games 成立于 2019 年，2021 年推出 Royal Match， 用一款在玩法上几乎没有任何新东西的三消，进入了这个被认为早已固化的市场， 并成为头部产品之一。

这件事本身就构成了一个值得拆的问题：

  1. 当玩法不再是差异化来源时，差异化到底发生在哪一层？
  2. 一个成熟品类的用户，为什么会从用了多年的产品迁移到新产品？迁移成本是被什么抵消的？
  3. 它的商业化和竞品在结构上有什么不同，还是说结构相同、只是执行更细？

我的结论偏向第三个答案，但「执行更细」是个没有信息量的说法。 这篇要做的是把「细」拆成可以描述、可以迁移的具体机制。

02最高频事件是失败

拆解一个循环，第一步不是画出所有节点，而是问：玩家在这个循环里最常经历的是哪一步？ 因为设计资源应该按事件频次分配，而不是按事件的「重要性感觉」分配。

这一点是整篇拆解的地基。绝大多数关于三消的讨论集中在「关卡怎么设计才好玩」， 但如果玩家在一个关卡上平均要失败若干次才能过，那么他在游戏里的大部分时间， 实际经历的是「我又没过」这个状态。

决定留存的不是通关那一刻有多爽，而是没通关那一刻有多不难受。

通关的快感是品类自带的——任何三消消除时都爽，这没有差异化空间。 失败的难受程度是可以设计的，而且各家差异很大。 Royal Match 的核心竞争力，我认为集中在这里。

03失败体验的设计

失败态由四个连续的环节组成，每个环节都可以单独优化：

环节玩家在想什么设计目标做错的后果
1. 失败瞬间的反馈 「啊，差一点」 弱化惩罚感，强调「差得很少」 沉重的失败音效 + 惩罚性动画 = 直接的负情绪，累积成卸载
2. 再试的摩擦 「还要点几下才能重来」 路径尽可能短，减少中断感 回到关卡列表再点进来，节奏断裂，玩家意识到「我在浪费时间」
3. 资源约束 「我还剩几条命」 制造稀缺感，但不制造挫败 体力过紧 = 强制下线；过松 = 失去付费与回访动机
4. 续关选择 「要不要花钱多几步」 在情绪峰值处提供出口 价格或时机不对 = 玩家感到被勒索，信任受损

「差一点」是被制造出来的

第 1 环节里最关键的机制是：让失败尽可能显示为「几乎成功」。 当玩家步数耗尽时，界面呈现的是「还差 N 个目标」，而不是「你失败了」。 当 N 很小时，玩家的归因是「运气差一点」而不是「我不行」。

这个差别在心理学上是外归因与内归因的差别， 而它直接决定了下一步行为：外归因导向「再试一次」，内归因导向「这游戏不适合我」。 失败界面的信息呈现方式，实质上是在引导玩家的归因方向。

体力系统的真实作用

体力（生命值）常被理解为纯粹的付费卡点。我认为它有一个更重要的作用： 强制中断连续失败。

连续失败会导致情绪的单调恶化。如果没有任何约束， 一个卡关的玩家可能连续失败十几次，最终以极差的情绪状态离开—— 而这个离开是不可逆的，因为最后一次会话的情绪决定了他是否还会回来。

体力耗尽强制中断了这个过程。它把玩家推离游戏时， 玩家的状态是「我没体力了」（外部原因）而不是「我过不去」（能力原因）。 这是一次体面的退出，它保护了下一次回访的意愿。

判断

体力系统的设计目标不该只用「付费转化」来评估， 还应该看「体力耗尽后的次日回访率」。 如果一个体力设计带来了短期付费提升但降低了次日回访，它是亏的。 很多产品把体力当成收费闸门来调，忽略了它同时是一个情绪保护装置。

04卡关的商业角色

卡关在三消里是一个被主动设计的商业事件，不是设计失误。 它是付费的主要触发点：玩家只有在「想过又过不去」时才会考虑买道具。

但卡关同时也是流失的主要来源。所以真正的设计问题是：

卡多久，玩家会付费；卡多久，玩家会走——这两个阈值之间的窗口有多宽？

难度的锯齿结构

成熟三消的难度曲线不是平滑上升的，而是锯齿状的：

  • 一段容易的关卡——建立节奏，累积「我很顺」的感觉，同时补充资源
  • 一个明显更难的关卡——制造卡点，触发付费决策
  • 紧接着一段容易的关卡——过掉硬关后立刻给予释放，把情绪拉回正值

第三段是最容易被忽略、也最关键的。硬关之后如果紧跟另一个硬关， 玩家会形成「后面只会越来越难」的预期，这个预期是流失的直接原因。 硬关后的轻松段，作用是重置玩家对难度趋势的判断。

硬关与 Meta 奖励节点的对齐

更进一步的设计是让硬关的位置和 meta 层的奖励节点对齐： 在玩家即将完成一个装修区域、即将拿到一个可见的成果时，放一个硬关。

这利用的是目标临近效应（goal-gradient effect）： 越接近目标，投入意愿越强。同样一个道具，在「随便哪一关」卖和在 「差一关就能看到新房间落成」时卖，转化率完全不同。

这也解释了 meta 层为什么要把进度做得高度可视—— 装修的进度条、待完成的区域、马上要变样的场景， 都是在把「还差多少」这件事持续呈现给玩家，为临近效应提供燃料。

这里的伦理边界

目标临近效应是一个中性的设计工具，但它的应用有明显的滥用空间： 如果硬关的难度是动态针对付费意愿高的玩家调高的， 那就从「设计节奏」滑向了「定向榨取」。 区别在于难度是对所有玩家一致还是因人而异。 判断线可以画在这里：可以设计卡点，不可以针对个人调整卡点强度。

05Booster 的两个决策时点

三消的道具体系分成两类，它们的差别不在效果，而在玩家做购买决策时掌握的信息量。 这个差别决定了它们完全不同的商业角色。

关前道具关内道具
决策时点进入关卡前眼看要失败时
玩家掌握的信息少：不知道这关难不难、棋盘会怎么生成多：清楚地看到差几步、缺什么
心理状态预防性投资，理性止损，情绪化
付费意愿较低峰值
商业角色培养道具使用习惯，抬高长期客单直接的收入来源
风险玩家觉得「用了也不一定过，浪费」过度使用会让玩家感到被勒索

免费发放的作用是建立效用认知

新手期大量免费发放道具，通常被理解为「让玩家爽一下」。 我认为它的真实作用更具体：让玩家亲身体验道具的效用值。

一个玩家如果从未用过某个道具，他无法评估它值不值那个价—— 面对购买选项时，他的默认判断是「不确定，那就不买」。 免费发放解决的是这个信息问题：用过之后，玩家心里有了 「这个道具大概能帮我多消掉多少」的量化认知， 后续的付费决策才从「要不要冒险」变成「值不值这个价」。

这是一个把不确定性转化为价格判断的过程。 所以免费发放的关键不是数量，而是是否覆盖了每一种道具至少一次—— 没被体验过的道具，在商店里基本卖不动。

06Meta 层的情绪分工

Royal Match 的 meta 是城堡装修：通关获得星星 / 资源，用来推进国王城堡各区域的修缮。 这个结构和 Playrix 的 Homescapes / Gardenscapes 同源。

关于 meta 层，最重要的设计原则我认为是一句话：

Meta 层必须是纯正反馈池，不能引入第二个失败点。

为什么

玩家的全部挫败都应该集中在三消层。三消层的挫败是有出口的—— 再试一次、用道具、等体力，路径清晰。

如果 meta 层也能失败（比如装修需要经营、有倒计时、资源会损失、决策可能选错）， 就出现了第二个负情绪源，而且这个负情绪源往往没有清晰的解决路径。 玩家的情绪曲线从「一个可控的锯齿」变成「两个互相干扰的锯齿」， 整体体验的可预测性下降，而可预测性正是休闲品类的核心价值。

所以 meta 层在这里承担的功能是单一且明确的：

  • 把抽象的关卡进度转译成可见的成果。「我过了 30 关」是抽象的，「这个房间变漂亮了」是具体的。
  • 提供中期目标。单关是短期目标，装修区域是中期目标，防止玩家在「过关—过关—过关」中失去方向感。
  • 为目标临近效应提供燃料（见第 04 节）。

Royal Match 的 meta 比同类更轻

相比 Homescapes 系列较重的剧情和角色互动，Royal Match 的 meta 更薄—— 叙事负担小，装修的选择项少，玩家不需要记住剧情线。

这是一个明确的取舍：牺牲叙事沉浸，换取认知负担的降低。 对一个主要在碎片时间被打开的产品来说， 「隔了三天回来还知道自己在干嘛」比「有一个动人的故事」更重要。 重剧情 meta 的隐性成本，是它对连续游玩的要求更高。

07留存机制

除了关卡本身，Royal Match 的回访理由主要来自周期性活动、赛季通行证和团队 / 竞赛玩法。 这些机制的共同点是：它们不是新玩法，而是给同一个玩法套上新的时限和排名。

关键在于它们各自解决的是不同的回访动机：

机制回访动机的类型作用于哪类玩家
限时活动损失厌恶：不上线就错过全体，尤其中低活跃
赛季通行证沉没成本：已经买了 / 已经推进了付费与高活跃玩家
竞赛 / 排行社会比较：不想掉名次竞争意愿强的少数玩家，但贡献高时长
团队协作社会义务：队友在等社交动机强的玩家，显著抬高长期留存

社交在这里不是玩法，是回访理由。 团队功能不改变三消的任何一步操作，它改变的是玩家「今天要不要打开这个 App」的判断依据—— 从「我想玩」扩展到「队友需要我」。这是一个成本极低、效果极强的留存杠杆。

08买量效率才是真正的护城河

前面七节讲的都是产品内的机制，但它们解释不了一件事： 为什么在这个品类里，做得好的产品有很多，做得大的产品却很少。

因为休闲游戏的竞争本质是一个买量生意。产品的规模上限由一个比值决定：

增长的约束条件

LTV / CAC > 1　—— 只要这个比值成立且有余量，买量就可以无限加码， 规模由资金效率而非产品质量决定；一旦不成立，产品再好也无法扩张。

所以真正的问题是：产品内的体验打磨，是怎么传导到这个比值上的？

路径一：失败体验 → 早期留存 → LTV

新用户流失最集中的时刻是前几次失败。第 03 节讲的所有细节—— 归因引导、再试摩擦、体面的退出——直接决定了次日和 7 日留存。 而留存是 LTV 最敏感的输入项：早期留存的小幅提升会在 LTV 上被放大。

路径二：广告与真实玩法的一致性 → CAC 的有效性

这是我认为最值得单独讲的一点。休闲游戏长期存在一种做法： 广告素材展示的是一个和真实玩法无关的小游戏（典型如「拔销子救人」）， 用它换取极高的点击率。

这种做法在账面上很划算，但它的代价被隐藏在漏斗的后半段：

  • 点击率高 → 单次安装成本看起来低
  • 但进来的用户想玩的是广告里那个游戏，不是三消
  • → 次日留存极差，大量安装是无效的
  • → 真实的「有效用户获取成本」远高于账面 CAC

Dream Games 在广告上更倾向于展示接近真实玩法的内容。 这个选择在短期指标上是吃亏的（点击率更低），但它换来的是 安装用户与产品的匹配度——进来的人本来就想玩三消。

用假广告买来的用户，留存差是必然的；账面 CAC 低，有效 CAC 反而高。

当产品有足够好的留存（路径一）时，它负担得起真实广告带来的更高点击成本； 而真实广告带来的高匹配度用户，又进一步抬高整体留存。 这两条路径互相强化，形成的复合优势，比任何单点的玩法创新都更难被复制。

回答第 01 节的问题

玩家为什么会从用了多年的产品迁移过来？ 我的答案是：迁移根本没有大规模发生。 Royal Match 的增量主要不是从 Candy Crush 抢来的存量用户， 而是通过更高效的买量，从「本来就会玩三消但还没被转化」的池子里持续获取的新用户。 在成熟品类里，竞争对手不是别的产品，是买量渠道里的出价。 这也是为什么执行细节的复利效应，在这个品类里比玩法创新更值钱。

09可迁移的结论

  1. 按事件频次分配设计资源。 先统计玩家最常经历的状态是什么，再决定把打磨精力放在哪。 很多产品在低频的高光时刻投入过度，在高频的日常状态上敷衍。
  2. 失败界面是归因引导装置。 呈现「差一点」而非「你输了」，把归因推向外部，直接影响再试意愿。
  3. 约束系统（体力）要同时用留存指标评估，不只用付费指标。 它保护的是最后一次会话的情绪状态。
  4. Meta 层只做正反馈，不做第二个失败点。 挫败必须集中在一个有清晰出口的地方。
  5. 短期指标最优的买量策略，往往不是长期最优。 评估广告素材要看安装后留存，不能只看点击率和安装成本。

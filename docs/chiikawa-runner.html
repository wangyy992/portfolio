ちいかわ 跑酷原型

72 小时 Game Jam · 设计说明

设计主张 IP 授权游戏最大的浪费，是把 IP 当成贴图。 一个成熟 IP 自带三样可直接消费的设计资产：世界观规则、进度框架、视觉语言。 本原型的全部设计决策都围绕一个问题展开—— 在 72 小时的硬约束下，哪些地方应该让位给 IP 已有的东西，哪些地方必须由设计自己扛。

01定位与 scope 边界

目标不是「在 72 小时内做完一款游戏」，而是用一个可玩原型回答一个具体问题： IP 授权游戏里，设计该在哪里让位给 IP，又该在哪里坚持。

选题来自市场观察。《ちいかわ》从推特短篇连载起家，2023 年起在国内快速扩散， 是目前谷子经济里最活跃的 IP 之一——联名频次高、线下快闪常态化排队、 核心受众是购买力强的年轻女性。这类高热度 IP 的授权游戏正在变多， 而多数做成了换皮：把角色贴到一个和 IP 毫无关系的玩法上。本原型想验证另一条路。

不做清单

对 jam 项目来说，明确不做什么比明确做什么更重要。 以下内容在立项时就排除，不在开发中途重新讨论：

不做理由
剧情与对话叙事无法在 72 小时内做到及格线，且会挤占手感调优时间
多角色 / 角色切换每个角色都要重做动画与判定，收益远小于成本
存档与结算画面原型的验证目标不涉及长期留存
音乐只做必要音效，音乐是可后补的表层
任何商业化设计同人性质，不涉及

02IP 选择与使用边界

为什么是这个 IP

除了热度，更重要的原因是：《ちいかわ》的世界观自带可玩结构。 它不是一个只有角色形象的 IP——角色靠讨伐怪物和除草打工谋生， 除草还有等级检定，考过才能接更高报酬的活。 这套设定本身就是一个现成的目标系统、一个现成的敌人库、一个现成的晋级框架。

它的识别点是「可爱外表 + 残酷规则」：画风萌，但世界是严苛的， 角色会累、会怕、会失败。这个反差是它能被成年人大量消费、 而不是停留在低龄向的根本原因，也是任何改编都不能丢的东西。

玩法类型的选择，是 IP 一致性的第一道题

原作里的角色不擅长战斗。所以这个 IP 应该做躲避，不应该做对抗。

这是本原型最先确定、也最关键的一个决定。 《ちいかわ》的角色面对怪物时，常态是害怕、逃跑、勉强应付， 而不是变强、反击、获胜。如果做成动作战斗游戏， 角色会被迫获得原作里不存在的力量，IP 的基调随之瓦解。

跑酷的核心动词是躲避——玩家不消灭威胁，只是设法通过。 这恰好是原作角色面对世界的方式。 玩法类型和 IP 的一致性，发生在动词层面，不在美术层面。

使用边界

内容处理原则
直接使用 角色形象、怪物形象、除草检定制度、既有表情 原样复用，不做再设计——复用的价值正在于玩家的既有认知
可以扩展 检定等级对应的具体考核内容、关卡场景的组合方式 在原作没有明确规定的地方补齐，但必须符合既有逻辑
不可改动 角色与怪物的力量关系、角色性格、世界观基调 角色不能打赢怪物；不能把世界改成纯欢乐向；不能让角色变得无所畏惧

第三行是最容易被违反的一条。做游戏的本能是给玩家成长与胜利感， 但这个 IP 的成长不是「变强」，而是「考过下一级」—— 这正是第 04 节要把检定当作进度系统的原因。

03核心循环

循环本身很短，关键在于其中埋了一个目标冲突： 草长在危险的位置，所以「安全通过」和「考过检定」不是同一条路线。

这个冲突不是为了增加难度而设计的，它直接来自 IP 的世界观： 在原作里，打工本身就是有风险的事。 角色除草是为了赚钱，而除草的地方就在怪物出没的范围里。 把这层设定翻译成玩法，就是「收集物必须放在危险附近」这一条规则。

判断

如果草均匀地铺在安全路线上，这个游戏就退化成了「躲障碍 + 顺手捡东西」， IP 只剩美术。收集物的位置是这个设计里唯一不能妥协的参数。

04除草检定：进度系统

进度系统直接使用原作既有的除草检定等级，从最低级起步，每通过一段升一级。

为什么不自建成长系统

  • 零教学成本。玩家看到「五级」「四级」立刻理解这是什么，不需要任何引导文案解释晋级意味着什么。
  • 目标感现成。「考过下一级」在原作里已经是角色的动机，玩家继承的是一个已被建立的欲望。
  • 符合 IP 的成长逻辑。如第 02 节所述，这个 IP 的角色不该「变强」，但可以「考过」。检定是唯一不破坏基调的成长形式。

等级结构

检定等级达标草数移动速度新增障碍类型
五级（起步）待对齐基准地面型
四级待对齐待对齐低空型
三级待对齐待对齐追击型
二级待对齐待对齐伪装型

达标线的设定原则：必须设在「全程走稳妥路线拿不到」的量上。 这是第 03 节那个目标冲突能否成立的唯一开关—— 达标线过低，玩家永远不需要冒险，冲突消失； 过高，稳妥路线完全无意义，玩家只能贴着危险跑，紧张感被拉平成疲劳。

实际调参时，建议以「稳妥路线可得量的 1.2–1.4 倍」作为起始达标线， 再按实测通过率调整。

05障碍设计：功能先行，形象后绑

障碍全部取自原作怪物，但设计顺序是先定义功能，再绑定形象，而不是反过来。

功能类型玩家应对动作设计作用绑定形象
地面型跳最基础的节奏单位，用于建立跳跃时机的肌肉记忆待指定
低空型下滑 / 不跳打破「一律跳过去」的惯性，强制读屏待指定
追击型持续加速，不能停压缩决策时间，制造持续压力而非单点威胁待指定
伪装型先辨认再决定把「识别」加进决策，最贴合 IP 的一类待指定

为什么坚持这个顺序

  1. 素材替换不破坏关卡设计。如果关卡是围绕某个具体怪物的形状设计的，换一个形象就得重做关卡；围绕功能设计，形象只是皮肤。
  2. 便于去 IP 化。同人作品无法商业化。如果日后要把这套设计用在别处，功能层可以整体保留。
  3. 避免为了用 IP 而用 IP。先想「这里需要一个逼玩家读屏的障碍」，再去找哪个怪物合适；而不是「这个怪物很有名，加进来」。
判断

伪装型是四类里唯一由 IP 直接催生的设计。 《ちいかわ》世界里「看起来无害的东西其实很危险」是反复出现的母题， 把它做成「远看像草丛，靠近才发现是怪物」的障碍， 是玩法在复述 IP 的叙事经验，而不只是借用它的形象。 这是本原型里 IP 使用得最深的一处。

06手感参数规格

跑酷的失败必须让玩家归因于「我按晚了」，而不是「这游戏不跟手」。 以下参数按这个目标设定：

参数规格理由
跳跃前摇 0 帧（输入即起跳） 跑酷里任何起跳延迟都会被感知为「不跟手」，这是挫败的最大来源
土狼时间
coyote time		 约 100 ms 离开平台边缘后仍可起跳。掩盖玩家的微小判断误差，代价几乎为零
输入缓冲
jump buffer		 约 100 ms 落地前按下的跳跃指令予以保留。连续跳跃时不会因为早按一帧而失败
落地缓冲 极短，不锁输入 落地硬直会打断跑酷的连续感，只保留视觉上的压缩表现
障碍最小间距 ≥ 人的反应时间 + 一次完整跳跃时长 低于此值的组合在物理上不可解，玩家会正确地认为这是设计失误
实测数值 待对齐——上表为设计目标，需与构建中的实际参数核对

土狼时间和输入缓冲这两项是玩家察觉不到、但拿掉就会明显变难受的典型。 它们的作用不是降低难度，而是让难度落在设计者想要的地方—— 应该难在读屏和决策，不该难在输入精度。

07关卡节奏

每个检定等级内部按四段推进：

  1. 教学段。本级新增的障碍类型单独出现，间距宽松，给足反应距离。新元素的第一次出现必须是无压力的。
  2. 组合段。新障碍与已掌握的类型混合，开始要求切换应对动作。
  3. 压力段。密度提高，草的位置更靠近危险，冒险与稳妥的取舍最尖锐。
  4. 检定点。结算草数，达标升级，未达标重来本段。
判断

压力段之后不应紧接下一级的压力段。 连续的高压会让玩家形成「后面只会更难」的预期，而这个预期是流失的直接原因。 下一级的教学段恰好承担了缓冲作用——它既是新内容的引入，也是情绪的重置。

08失败与反馈

  • 失败条件：碰到障碍即失败，或到达检定点时草数未达标。
  • 重开路径：立即重开当前段，不返回任何菜单。跑酷的失败频率高，任何多余的一次点击都会被放大成烦躁。
  • 失败表现：复用原作角色既有的慌张 / 脱力表情。这类表情本身就有高辨识度和情绪缓冲作用——失败画面很可爱，是这个 IP 的天然优势。
  • 失败文案：显示「还差 N 株」，而不是「失败」。 当 N 很小时，玩家会把原因归给运气而非能力， 归因方向直接决定他是再试一次还是关掉。

09资产策略

72 小时里，任何新做的资产都在挤压手感调优的时间。执行原则只有一条：

任何需要新做的资产，先问能不能用既有素材的变体代替。

  • 角色与怪物：全部使用原作既有形象，不做再设计。
  • 失败与状态反馈：使用既有表情，不新做动画。
  • 场景：以少量元素的重复组合构成，靠速度和密度制造变化，而不是靠新场景。
  • 音效：只保留跳跃、除草、碰撞三个，其余不做。

这套策略之所以成立，前提是选了一个视觉语言高度统一的 IP。 原作画风扁平、线条简洁、配色克制，任何元素放在一起都自然协调—— 这是选题阶段就已经预支的收益。

10排期与实现

时段目标完成判据
0–12h移动、跳跃、碰撞角色能跑能跳，碰到方块会死
12–30h障碍生成与四类障碍四类障碍可配置出现，关卡可跑通
30–48h除草收集与检定结算能捡草、能结算、能升级
48–60h关卡节奏与草的分布调优目标冲突在实际游玩中能被感知到
60–72h手感打磨与打包可交付的可玩版本

排期的关键是把手感打磨放在最后而不是最前： 在关卡节奏定下来之前调手感，参数会被反复推翻。

11已知问题与下一步

原型未覆盖

  • 存档与跨会话进度
  • 音乐与完整音效层
  • 多角色与角色差异化
  • 检定失败次数过多时的引导或补偿

下一步要验证的问题

  1. 目标冲突是否真的被玩家感知到。 需要实测：玩家是否出现过「明知危险仍绕过去拿草」的行为。 如果玩家全程走稳妥路线仍能达标，说明第 04 节的达标线设低了，整个设计的核心失效。
  2. 伪装型障碍的辨认时间是否足够。 它是四类里唯一要求「先识别再反应」的，如果辨认窗口过短，玩家会觉得不公平而非紧张。
  3. 不熟悉原作的玩家能否理解检定目标。 零教学成本的前提是玩家认识这个 IP。需要找几个没看过原作的人测一遍， 确认在没有既有认知时，这套目标系统是否还能自解释。
这条最重要

第 3 条是对整篇策划案核心论证的反向检验。 本文反复主张「IP 的已知性可以当作设计资产直接消费」， 但这个主张只在玩家确实拥有那份认知时成立。 测出边界在哪里，比再多写一层论证都有价值。

12IP 合规声明

非商业同人作品

本项目为个人练习性质的非商业同人原型，用于设计能力的学习与验证。 《ちいかわ》的角色、怪物形象及相关世界观设定， 版权归原作者ナガノ及其授权方所有。

本原型不用于任何商业用途，不进行付费分发、不接受赞助、不用于任何形式的变现。 如权利方提出异议，将立即下架相关内容。

说明：第 05 节坚持「功能先行、形象后绑」的设计顺序， 除了关卡设计上的理由之外，也使这套设计在移除 IP 素材后仍然完整可用。

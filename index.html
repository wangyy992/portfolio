光与影｜双角色机关解谜

个人开发 · 16 关 · 已上线
Puzzle Level Design Core Mechanic

全黑场景，双角色同屏合作解谜，共 16 关。光灵离开光就消散，影灵被光照到就消散； 灯可以推着走。每移动一次灯，两条路径同时反向翻转—— 一个人的路打开，另一个人的路随之断开。两人必须同时站进各自的门才算过关。

  • 两个角色的规则严格镜像，这是机制成立的前提。 若限制不对称，一个谜题会退化成两个互不相干的谜题； 镜像规则下玩家只需理解「亮暗互补」一件事，就能自动推演两边后果—— 认知成本减半，谜题深度不变。
  • 光的渲染与致命判定是两套系统，且渲染必须服从判定。 判定阈值在灯半径 55% 处，渲染亮度必须在此之后迅速收掉； 否则会出现「看着危险其实安全」的光晕，玩家绕开本可通行的路， 解空间被视觉误导缩小，而他只会觉得这关无解。
  • 护盾 0.28 秒是规则参数，不是手感参数。 跳跃穿过光柱的暴露时间约 0.34 秒——护盾设在其下，硬闯必死； 一旦放宽到 0.34 秒以上，会跳的玩家可直接冲过所有光柱， 「光是屏障」的设定当场失效，全部关卡同时被破解。
  • 三个可达性数字定义了关卡的全部语法。 普通跳 2.5 格、站在灯上 3.4 格、最大水平跳 3.9 格—— 于是「3 格墙」等于「这里必须用灯」，读格子数就能判断可解性，不必试玩验证。
  • 全程只有一种可交互物件，靠叠加互斥用途换取组合空间。 灯同时是光源、垫脚箱子和常压板配重，三者互相冲突—— 「只有一盏灯而有两件事要做」因此成为最经济的谜题模板。

ちいかわ 跑酷｜IP 向横版跑酷

个人开发 · Web · 已上线
IP Game Runner Game Feel

以《ちいかわ》（Chiikawa）为素材的横版跑酷，已上线可玩。 玩家被讨伐队追赶，靠躲避怪物与荆棘拉开距离；金币成串悬在每个障碍的正上方—— 吃到它们能补充领先距离，而领先距离决定能跑多远。 进度不是分数，是原作设定里的「除草检定」等级，每跑 800m 晋一级。

  • 选题来自市场观察，不是个人偏好。 ちいかわ 从推特短篇连载起家，2023 年起在国内快速扩散， 是目前谷子经济里最活跃的 IP 之一——联名频次高、线下快闪常态化排队、 核心受众是购买力强的年轻女性。这类高热度 IP 的授权游戏正在变多， 做这个项目是想弄清一个具体问题：IP 授权游戏里，设计该在哪里让位给 IP，又该在哪里坚持。
  • 把「打工考证」而不是「战斗」设为核心目标。 ちいかわ 的识别点是「可爱外表 + 残酷规则」——角色靠讨伐怪物和除草打工谋生， 除草还要考等级检定。做成战斗跑酷会丢掉这层反差， 变成任何萌系角色都能替换的皮；做成考证跑酷，这个 IP 才是不可替代的。
  • 撞到障碍不是即死，而是被追击者拉近。 撞一次损失 80px 领先距离，约需 6 秒不失误才能补回。 即死表达的是「一击致命」，消耗表达的是「被追得筋疲力尽」—— 后者才是原作角色的真实处境。失误可挽回但要付出时间， 这段「我得稳一会儿」的状态本身就是有质感的体验。
  • 收集物悬在危险正上方，用风险换生存资源。 每个障碍生成时，4 枚金币同时挂在它正上方 55px；连击每 5 枚补充领先距离。 所以玩家不是为「凑够数量」冒险，而是为「活得更久」冒险—— 收益连续而非阶跃，决策因此一直存在。实测两种跑法收益相差约 2 倍。
  • 用 IP 自带的晋级框架替代自建数值。 除草检定在原作里已是读者熟悉的等级体系，直接拿来当进度， 省掉一整套自定义成长系统的设计与教学成本。
  • 难度用两条相反的曲线控制。 速度随距离升到 1.62 倍后封顶，而障碍间距持续放宽—— 后期压力从「反应速度」转移到「领先距离的经营」，难度的性质变了而不只是数值变了。

这个项目验证的是 IP 的「已知性」本身就是可以直接消费的设计资产—— 它同时提供世界观规则、进度框架与视觉语言。用好能大幅压缩设计成本，用不好就只是贴图换肤。 技术上为零依赖零构建、固定步长 1/120s、可直接 file:// 打开。

非商业同人作品。《ちいかわ》角色、怪物及相关设定版权归原作者ナガノ及授权方所有，本作不用于任何商业用途。

爱豆收集梦想生活｜AI 驱动沙盒养成游戏

独立产品设计 / 全栈开发 · Web · 2026
AI Gameplay Simulation System Design

Tomodachi-Life 风格的俯视沙盒养成游戏。核心采用“确定性模拟 + 生成式 AI”混合架构： 游戏系统管理时间、角色状态、日程和关系数值，LLM 只负责生成当前情境下的对话与剧情， 以提升内容自由度，同时保证世界状态连续、规则可控。

  • 设计角色关系、世界事件、虚拟社交平台、角色创建等核心系统。
  • 通过结构化 AI 输出，将生成内容解析并写回关系、事件与游戏状态。
  • 使用 DeepSeek，并通过上下文裁剪降低 token 消耗与响应成本。
  • 结合角色素材包搭建可自定义捏脸系统，并使用 Gemini 生成游戏内角色、美术及场景素材。
  • 技术栈：React 19 / TypeScript / Vite / Tailwind CSS v4。

结果2000+ 用户体验，出现社交媒体自发传播。

AI 狼人杀｜1 名玩家 vs 11 个 AI Agent

独立设计开发 · Multi-Agent Social Deduction · 2026
Multi-Agent Social Deduction AI Behavior

玩家独自进入 12 人狼人杀对局，其余 11 个位置由 AI Agent 控制。重点不是“AI 会聊天”， 而是让每个 Agent 拥有角色信息、记忆、怀疑、立场与行为决策，形成真实的多人社交推理体验。

  • 拆分公开信息、身份私有信息与 Agent 局部记忆。
  • 探索不同人格与角色 prompt 对发言、投票、跟票和欺骗行为的影响。
  • 重点研究 AI 的 herd behavior、信息污染与错误推理问题。

光与影｜双角色机关解谜

玩法设计 / 关卡设计 · WIP
Puzzle Level Design Core Mechanic

全黑场景中，灯可以被推动、开关与遮挡。光灵只能走在光照区域，影灵依赖阴影前进。 玩家每一次移动灯光，都会同时改变两个角色的可行路径：一个人的路打开，另一个人的路可能随之断开。

  • 以“同一环境状态对两个角色产生相反影响”作为核心机制。
  • 关卡按开关灯 → 推灯 → 遮挡 → 多光源逐步增加复杂度。
  • 最终目标是让两个角色同时抵达各自终点。

01

爱豆收集梦想生活

AI 驱动沙盒养成游戏
独立产品设计 / 全栈开发 · Web · 2026

Tomodachi-Life 风格的俯视沙盒养成游戏。核心采用“确定性模拟 + 生成式 AI”混合架构：游戏系统管理时间、角色状态、日程和关系数值，LLM 只负责生成当前情境下的对话与剧情，以提升内容自由度，同时保证世界状态连续、规则可控。

01设计角色关系、世界事件、虚拟社交平台、角色创建等核心系统。
02通过结构化 AI 输出，将生成内容解析并写回关系、事件与游戏状态。
03使用 DeepSeek，并通过上下文裁剪降低 token 消耗与响应成本。
04结合角色素材包搭建可自定义捏脸系统，并使用 Gemini 生成游戏内角色、美术及场景素材。
05技术栈：React 19 / TypeScript / Vite / Tailwind CSS v4。
RESULT
2000+ 用户体验，出现社交媒体自发传播。

02

AI 狼人杀

1 名玩家 vs 11 个 AI Agent
独立设计开发 · Multi-Agent Social Deduction · 2026

玩家独自进入 12 人狼人杀对局，其余 11 个位置由 AI Agent 控制。重点不是“AI 会聊天”，而是让每个 Agent 拥有角色信息、记忆、怀疑、立场与行为决策，形成真实的多人社交推理体验。

01拆分公开信息、身份私有信息与 Agent 局部记忆。
02探索不同人格与角色 prompt 对发言、投票、跟票和欺骗行为的影响。
03重点研究 AI 的 herd behavior、信息污染与错误推理问题。

03

光与影

双角色机关解谜
个人开发 · 已上线

全黑场景，双角色同屏合作解谜。光灵离开光就消散，影灵被光照到就消散；灯可以推着走。每移动一次灯，两条路径同时反向翻转——一个人的路打开，另一个人的路随之断开。两人必须同时站进各自的门才算过关。

01两个角色的规则严格镜像：玩家只需理解「亮暗互补」一件事，就能自动推演两边后果。
02光的渲染必须服从致命判定，阈值在灯半径 55%——否则光晕会误导玩家，缩小解空间。
03灯同时是光源、垫脚箱子和压板配重，三种互斥用途撑起全部谜题组合。

04

ちいかわ 跑酷

IP 向横版跑酷
个人开发 · Web · 已上线

以《ちいかわ》（Chiikawa）为素材的横版跑酷，已上线可玩。玩家被讨伐队追赶，靠躲避怪物与荆棘拉开距离；金币成串悬在每个障碍的正上方——吃到它们能补充领先距离，而领先距离决定能跑多远。进度不是分数，是原作设定里的「除草检定」等级，每跑 800m 晋一级。

01选题来自市场观察：ちいかわ 是谷子经济里最活跃的 IP 之一，想弄清授权游戏里设计该在哪让位给 IP、又在哪坚持。
02把「打工考证」而不是「战斗」设为核心目标——「可爱外表 + 残酷规则」的反差才是这个 IP 不可替代的部分。
03撞障碍不是即死，而是损失 80px 领先距离；金币悬在障碍正上方，用风险换生存资源。
